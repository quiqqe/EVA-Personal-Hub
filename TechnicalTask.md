# EVA Personal — техническое задание

Сайт — сборник личных инструментов. Общие для всех инструментов:
пользователи, вход, группы людей (семья, друзья). Первый инструмент — **учёт средств** («Деньги»).

## §1. Платформа (хаб)

1. Регистрация и вход по email + пароль. «Запомнить меня». Смена имени, пароля, базовой валюты в профиле.
2. Главная страница `/` — список инструментов (плитки). Новый инструмент = новая плитка + свой раздел URL.
3. **Группы** — общая сущность хаба:
   - любой пользователь создаёт группу (становится владельцем);
   - приглашение по ссылке `/join/{token}`; владелец может перевыпустить ссылку (старая перестаёт работать);
   - владелец удаляет участников, переименовывает группу, меняет валюту группы;
   - участник может выйти из группы; владелец — удалить группу (только если в ней нет операций).
4. Интерфейс: веб, mobile-first (основное использование — с телефона), светлая и тёмная тема (по системе или вручную),
   собственные шрифты, можно добавить на главный экран (PWA manifest).

## §2. Деньги: пространства (scope)

Всё в инструменте живёт в **пространстве**: «Личное» (только моё) или группа (общее для участников).
Переключатель пространства — в шапке. URL: `/money/me/...` или `/money/{groupId}/...`.

- В личном пространстве видно только своё.
- В групповом видно общие счета группы и все операции группы; все участники могут их создавать и править.
- Операцию, созданную в группе с личного счёта (например, «я оплатил ужин картой»), видно и в группе,
  и в личном пространстве владельца счёта (это его реальный расход с карты).

## §3. Счета

- Типы: наличные, карта, банковский счёт, накопления/вклад, кредитка/кредит, инвестиции, **долги**, прочее.
- У счёта: название, тип, валюта, начальный остаток. Можно архивировать (скрыт, история сохраняется).
  Удалить можно только счёт без операций.
- Баланс = начальный остаток + доходы − расходы − исходящие переводы + входящие переводы.
- **Личные долги** («дал в долг Васе», «занял у мамы») — счёт типа «долги» на человека:
  дал в долг = перевод с наличных на счёт «Вася» (баланс > 0 — мне должны), вернул — перевод обратно.

## §4. Операции

- Типы: расход, доход, перевод между счетами.
- Поля: сумма, счёт, категория (для расхода/дохода), дата (по умолчанию сегодня), комментарий.
- Сумма вводится с клавиатуры телефона; допускаются пробелы, запятая и простые выражения `250+120-30`.
- Перевод между счетами в разных валютах — с указанием суммы зачисления (фактический курс).
- Переводы можно делать между своими счетами и счетами своих групп (пополнить общую копилку).
- Список: по месяцам с навигацией, фильтры по счёту, категории, типу; поиск по комментарию.
- Редактирование и удаление любой операции в пространстве.
- Быстрый ввод: по умолчанию подставляется последний использованный счёт.

## §5. Категории

- Отдельно для расходов и доходов, у каждого пространства свои. При создании пространства — набор по умолчанию.
- Эмодзи-иконка, переименование, архивирование.

## §6. Мультивалютность и криптовалюты

- Каждый счёт в своей валюте: фиат (ISO 4217, те, что котирует ЦБ РФ) или крипта (USDT, USDC, BTC, ETH, TON, SOL, TRX, BNB, LTC, XRP, DOGE)
  с нужной точностью (BTC — 8 знаков, USDT — 6). Крипта участвует везде так же, как фиат: доходы, расходы, переводы,
  деление трат, долги, бюджеты, цели, отчёты.
- **Обмен** (например, USDT → AMD в офлайн-обменнике) — перевод между счетами в разных валютах: указывается полученная сумма
  или курс обменника, второе считается. Фактический курс виден в операции.
- Итоги (капитал, доходы/расходы, отчёты) можно смотреть **в любой валюте** — переключатель «в …», выбор запоминается
  на время сессии. По умолчанию — базовая валюта пользователя / группы.
- Бюджет задаётся в любой валюте; траты во всех валютах пересчитываются в неё.
- Пересчёт по курсу на сегодня: фиат — ЦБ РФ (`cbr-xml-daily.ru`, кэш 6 ч), крипта — CoinGecko (кэш 1 ч).
  Если курс недоступен — эти суммы показываются отдельно с пометкой.

## §7. Деление трат и долги в группе (как Splitwise)

- В группе при расходе можно отметить «Разделить»: кто платил (участник) и между кем делить (по умолчанию все).
  Делится поровну, копейки остатка — первым участникам.
- Если платил я — выбираю свой личный счёт, расход списывается с него.
  Если платил другой участник — счёт не указывается, только валюта.
- Страница «Долги»: баланс каждого участника по каждой валюте и упрощённый список «кто кому сколько должен»
  (минимум переводов). Кнопка «Рассчитаться» записывает возврат долга.

## §8. Бюджеты и цели

- Бюджет — месячный лимит на категорию расходов в валюте пространства; прогресс за текущий месяц, предупреждение при превышении.
- Цель — название, целевая сумма, срок (опционально), привязанный счёт-копилка; прогресс = баланс счёта.

## §9. Регулярные операции

- Шаблон операции (расход/доход/перевод) + периодичность: день, неделя, месяц, год + дата начала.
- Операции создаются автоматически при заходе в пространство за все пропущенные даты до сегодня.
  «31-е число» в коротких месяцах → последний день месяца.
- Пауза / удаление шаблона.

## §10. Импорт и экспорт

- Импорт CSV-выписки банка в выбранный счёт: автоопределение кодировки (UTF-8 / Windows-1251) и разделителя,
  угадывание колонок «дата / сумма / описание / категория» по заголовкам, предпросмотр, ручной выбор колонок.
  Отрицательная сумма — расход, положительная — доход (галочка «инвертировать знак»).
- Категория при импорте: по прошлым операциям с тем же описанием, иначе по категории банка (название или типовой синоним: «Супермаркеты» → «Продукты»).
- Повторный импорт той же выписки не создаёт дублей.
- Экспорт всех операций пространства в CSV (UTF-8, `;`, открывается в Excel).

## §11. Отчёты

- За месяц: доходы, расходы, разница; расходы и доходы по категориям с долями.
- Динамика за 12 месяцев: доходы и расходы по месяцам.

## §12. Нефункциональные требования

- Стек: PHP 8.3, Symfony 7.4, PostgreSQL 16, Twig, без JS-сборки. Docker Compose, наружу публикуется только nginx проекта и только на localhost.
- Деньги хранятся целыми числами в минимальных единицах валюты (копейки), без float.
- Все формы — с CSRF. Доступ к чужому пространству/объекту — 404.
- Изменения схемы — только миграциями.

## Вне первой версии

Восстановление пароля по email (нужен почтовый сервис), Telegram-бот, неравное деление трат,
исторические курсы для старых операций, вложения (чеки).

## Решения

- Инфраструктура, домены и деплой не хранятся в репозитории (история переписана 2026-10-21).
- Шрифты хостятся локально (`public/fonts`), без внешних CDN. Градиент бренда одинаково тёмный в обеих темах — белый текст на нём читается.
- Пересчитанные итоги показываются округлёнными до целых (копейки при пересчёте — шум); остатки счетов — точно.

- Без DDD-слоёв как в NovaChat: проект — CRUD, поэтому сущности Doctrine с атрибутами и публичными свойствами,
  контроллеры + Twig, логика с расчётами — в отдельных классах с unit-тестами.
- Пользователи и группы — общие для хаба (`src/Entity`), инструмент «Деньги» — `src/Money`.
- Формы — обычный HTML + ручная валидация + CSRF, без Symfony Form (меньше кода, проще мобильная вёрстка).
- Регулярные операции создаются лениво при заходе в пространство (без cron), с блокировкой строки шаблона.
- Курсы: операции — по курсу своего дня (снимки с 03.2024 + архив ЦБ раньше, хранятся в БД), остатки — по сегодняшнему.
- Сортировка по UUID v7, а не по createdAt (timestamp(0) — одинаковые секунды давали случайный порядок).
- Список валют — только актуальные, которые котирует ЦБ (+ крипта), чтобы любая валюта пересчитывалась.
- Импорт: категория сначала по прошлым операциям с тем же описанием (выбор человека важнее), затем по категории банка + словарь синонимов.
